## 🎯 使用建议

### 首次使用
1. 双击 `run.bat` 或在命令行运行
2. 选择选项 1（快速测试）
3. 确认测试通过后，再选择选项 2（正式运行）

### 命令行方式
```bash
# 测试
python test_quick.py

# 正式运行
python compute_valid_params.py
```

## ⚙️ 系统要求

### 软件要求
- Python 3.7+
- 依赖包：
  - pandas
  - numpy
  - seaborn
  - matplotlib

### 硬件要求
- 内存：建议 8GB+
- 磁盘：预留几GB空间（用于存储生成的图片）
- CPU：多核处理器可加速计算（但当前版本未使用并行）

## 📝 注意事项

1. **不要修改原始数据**
   - 所有计算都是只读操作
   - 不会影响 `catch_opinion_6all.csv`

2. **备份重要数据**
   - 虽然不会修改源数据，但建议定期备份

3. **长时间运行**
   - 正式运行可能需要数小时
   - 建议在稳定的环境中执行
   - 确保计算机不会进入睡眠模式

4. **磁盘空间**
   - 合法参数可能有几百到上千个
   - 每个图片约几百KB
   - 请预留足够的磁盘空间
