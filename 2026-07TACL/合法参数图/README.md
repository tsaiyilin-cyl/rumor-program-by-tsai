# 合法参数图

## 项目说明

本项目用于在超参数空间网格搜索中，仅对合法的参数组合绘制影响力热力图。

## 功能特点

1. **合法性检查**：遍历所有参数对 (id, yd)，使用 `is_valid_hyperparam()` 函数检查是否满足约束条件 `c12 > c11_c21 > c22 > c11_c31`
2. **非法参数处理**：不合法的参数组合直接跳过（相当于涂白）
3. **损失矩阵计算**：对合法参数计算15x15固定网格的损失矩阵，与理想矩阵对比
4. **数据过滤**：只保留以下四个模型的数据：
   - DeepSeek-V3.2
   - GPT-5.1
   - Llama-3.3-70b-instruct
   - Gemini-3.1-Flash-Lite-Preview

### 损失矩阵说明

每个合法参数生成一个15x15的损失矩阵图：
- **纵轴**：ave_In（平均负向影响力），从下往上升序
- **横轴**：ave_Ip（平均正向影响力），从左往右升序
- **基准线**：左下-右上对角线（y=x），表示 ave_Ip == ave_In，理论观点应为0
- **理想分布**：距离基准线越远，观点值应越远离0
  - 左上区域（ave_In > ave_Ip）：观点趋向 -1
  - 右下区域（ave_Ip > ave_In）：观点趋向 +1
- **损失计算**：比较实际秩次与理想秩次的偏差 `abs(b_actual - b_ideal)`
- **缺失处理**：无数据的格子损失为0，并动态调整理想秩次范围

## 核心逻辑

### 参数范围
- 时间步衰减系数 (id): 1.0 ~ 1.51，步长 0.01
- 观点变化增益系数 (yd): 1.0 ~ 1.51，步长 0.01
- 总计约 2601 个参数组合

### 合法性约束
```python
def is_valid_hyperparam(id_val, yd_val):
    c12 = id_val^(-1) * 2^yd_val
    c11_c21 = id_val^(-1) * 1^yd_val + id_val^(-2) * 1^yd_val
    c22 = id_val^(-2) * 2^yd_val
    c11_c31 = id_val^(-1) * 1^yd_val + id_val^(-3) * 1^yd_val
    
    return c12 > c11_c21 > c22 > c11_c31
```

### 输出内容
每个合法参数组合生成一张损失热力图，展示：
- **矩阵大小**：固定15x15网格
- **颜色编码**：每个格子的损失值 `abs(b_actual - b_ideal)`（黄色=低损失，红色=高损失）
- **数值标注**：每个格子显示具体的损失值
- **标题信息**：包含总损失和有效格点数
- **文件名格式**：`loss_id{id值}_yd{yd值}.png`

## 注意事项

1. **不修改原始数据**：所有计算基于原始数据文件，不会修改任何源数据
2. **计算量较大**：需要对每个合法参数组合重新计算影响力矩阵，可能需要较长时间
3. **内存占用**：建议确保有足够的内存来处理大规模数据
