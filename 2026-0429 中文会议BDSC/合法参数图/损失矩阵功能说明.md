# 损失矩阵功能说明

## 功能概述

本功能通过**量化评估**每个超参数对 `(id, yd)` 的表现与理想状态的偏差，生成参数空间得分热力图。核心思想是验证"观点值应随 `ave_In - ave_Ip` 单调变化"的假设。

## 核心改进

### 1. 固定10×10网格
- 不再根据数据值域动态分箱
- 所有参数对使用统一的10×10网格结构
- 便于不同参数对之间的横向比较

### 2. 理想矩阵定义

#### 坐标系统
- **纵轴（Y）**：ave_In（平均负向影响力），从下往上升序（索引0-9）
- **横轴（X）**：ave_Ip（平均正向影响力），从左往右升序（索引0-9）

#### 基准线（y=x）
- 左下到右上的对角线表示 `ave_Ip == ave_In`
- 理论上，这条线上的点平均观点应接近0

#### 理想分布规律
- **左上区域**（ave_In > ave_Ip，即 y = x + b, b > 0）：
  - 负向影响力占主导
  - 观点应趋向 -1
  
- **右下区域**（ave_Ip > ave_In，即 y = x + b, b < 0）：
  - 正向影响力占主导
  - 观点应趋向 +1

- **距离基准线越远**，观点值应越远离0

### 3. 秩次分配规则

#### 理论秩次范围
将所有有效格子按观点值从小到大排序（从-1到+1）：

```
y = x + 9 (最左上): 秩次 1
y = x + 8: 秩次 2, 3
y = x + 7: 秩次 4, 5, 6
...
y = x + 0 (基准线): 中间秩次
...
y = x - 7: 倒数第6, 5, 4个秩次
y = x - 8: 倒数第3, 2个秩次
y = x - 9 (最右下): 最后1个秩次
```

#### 缺失数据处理
如果某条对角线上没有有效格子：
- 该对角线的损失为0
- 动态调整后续对角线的秩次范围

**示例**：
- 原本 y=x+8 应有2个点，秩次范围[2,3]
- 如果只有1个点，则范围变为[2,2]
- y=x+7 原本应为[4,6]，现在调整为[3,5]
- 依此类推...

### 4. 相同值格子的最优分配

**问题**：当多个格子具有相同的观点值时，如何分配秩次？

**解决方案**：
1. 将相同值的格子分为一组
2. 为该组分配连续的秩次范围
3. 找出该秩次范围可能对应的所有候选对角线
4. 对组内每个格子，尝试所有候选对角线，**选择使损失最小的那个**

**优势**：
- 避免因排序任意性导致的不合理损失
- 相同观点值的格子都能获得最优的损失分配
- 总损失更小、更合理

### 5. 0-1损失函数

对于每个有效格子：
1. 确定其实际位置的对角线：`b_actual = i - j`（i为纵轴索引，j为横轴索引）
2. 根据其秩次找到应在的理想对角线：`b_ideal`
3. 计算损失：
   ```python
   loss = 0 if b_actual == b_ideal else 1
   ```

**为什么用0-1损失而不是距离损失？**
- 避免重复计算：当一个点错位时，必然有另一个点也被影响，距离损失会重复计算这种连锁效应
- 物理意义清晰：总损失 = 不符合单调性假设的格子数量
- 更易解释：如果总损失是5，意味着有5个格子偏离了理想模式

**总损失** = 所有有效格子损失的总和（即错位的格子数）

### 6. 归一化与得分计算

#### 归一化损失
```
normalized_loss = total_loss / valid_count
```
其中 `valid_count` 是有效格点数（有数据的格子数）

#### 得分计算
```
score = 1.0 - normalized_loss
```
- **满分1.0**：所有格子都符合单调性假设（完美）
- **最低分0.0**：所有格子都不符合假设（最差）
- 得分越高，参数表现越好

**示例**：
- 参数 (1.20, 1.08)：总损失=16，有效格点=51
- 归一化损失 = 16/51 ≈ 0.3137
- 得分 = 1 - 0.3137 ≈ 0.6863

### 7. 可视化输出

#### 总参数空间热力图
所有合法参数对的得分绘制在一张图中：

**图表元素**：
- **颜色编码**（黄-红配色）：
  - 黄色：高分（接近1，好参数）
  - 红色：低分（接近0，差参数）
  - 白色：非法参数（不满足约束条件）
  
- **标题**：
  ```
  Parameter Space Score Heatmap
  (Yellow=High Score, Red=Low Score, White=Invalid)
  ```

- **坐标轴**：
  - X轴：id_val (Influence Decay)
  - Y轴：yd_val (Opinion Sensitivity)

#### 文件名
```
overall_score_heatmap.png
```

### 8. 数据持久化

所有参数对的计算结果保存到CSV文件，避免重复计算：

**文件**：`parameter_space_results.csv`

**包含字段**：
- `id_val`: id参数值
- `yd_val`: yd参数值
- `is_valid`: 是否合法（True/False）
- `total_loss`: 总损失（仅合法参数）
- `valid_count`: 有效格点数（仅合法参数）
- `normalized_loss`: 归一化损失（仅合法参数）
- `score`: 得分（仅合法参数）

**优势**：
- 修改可视化效果时无需重新运行耗时的计算
- 可直接分析特定参数范围的得分分布
- 方便找出得分最高/最低的参数组合

## 技术细节

### 数据流程
1. 加载原始数据（6个目标模型）
2. 遍历所有超参数组合（id: 1.0-1.51, yd: 1.0-1.51, 步长0.01，共2601个）
3. 对每个参数对：
   - 检查合法性：`c12 > c11_c21 > c22 > c11_c31`
   - 如果不合法：记录并跳过
   - 如果合法：进行后续计算
4. 保存所有结果到CSV文件
5. 绘制总参数空间得分热力图

### 关键函数

#### `compute_ideal_matrix_and_loss(df_filtered, id_val, yd_val)`
- 输入：过滤后的DataFrame和参数值
- 输出：`(total_loss, valid_count, loss_matrix, value_matrix, count_matrix)`
- 功能：计算10×10矩阵的损失，使用0-1损失函数和相同值最优分配

#### `plot_overall_score_heatmap(score_matrix, id_vals, yd_vals, output_dir)`
- 输入：所有参数对的得分字典和参数值列表
- 输出：保存总体热力图到PNG文件
- 功能：绘制黄-红配色的参数空间得分热力图

## 注意事项

1. **计算时间**：需要遍历2601个参数组合，其中合法的约几百个，总体耗时较长（可能需要数小时）
2. **内存占用**：建议确保有足够内存（8GB+）
3. **磁盘空间**：预留几十MB存储CSV文件和热力图
4. **数据持久化**：计算完成后会保存CSV文件，后续如需修改可视化效果可直接读取CSV，无需重新计算
5. **缺失数据**：无数据的格子不参与损失计算，但会据此调整后续秩次分配
6. **浮点数精度**：相同值判断时使用四舍五入到小数点后10位，避免浮点数精度问题
