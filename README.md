## BDSC (CAAI第十一届全国大数据与社会计算学术会议)

### 研究主题
**《对齐的错觉：多智能体硅基社会中偏见的碎片化与认知扰动》**

### 核心目标
研究多智能体系统中不同大语言模型在辩论过程中表现出的偏见传播、信息影响力及固执度特征，探索智能体社会中的"对齐错觉"现象。

### 研究内容

#### 1. 实验设计
- **参与模型**: 4个主流大语言模型
  - DeepSeek-V3.2
  - GPT-5.1
  - Llama-3.3-70b-instruct
  - Gemini-3.1-Flash-Lite-Preview

- **实验配置**:
  - 6个不同话题(topic)
  - 35组超参数实验(experiment_index: -4到30)
  - 每轮辩论最多11轮迭代
  - 6个具有不同性别和种族属性的智能体（基线为6个无身份属性的智能体）

#### 2. 关键指标

**影响力( Influence )指标**:
- `posi`: 正向影响力 (Positive Influence)
- `negi`: 负向影响力 (Negative Influence)

**固执度( Stubbornness )指标**:
- `poss`: 正向固执度 (Positive Stubbornness)
- `negs`: 负向固执度 (Negative Stubbornness)

**聚合统计**:
- `ave_Ip/In/Sp/Sn`: 各指标的平均值
- `max_Ip/In/Sp/Sn`: 各指标的最大值

#### 3. 收敛性分析
- **稳态轮次**: 系统达到稳定状态所需的轮次
- **达成共识轮次**: 所有智能体观点一致的轮次
- **共识观点**: 最终达成的共识值
- **末轮观点分布**: 包括一致(consistent)、两极分化(polar)和碎片化状态
- **末轮平均观点**: 最终轮次的平均观点值

#### 4. 超参数空间探索
通过遍历影响力衰减参数(id)和观点差异敏感度(yd)的超参数空间：
- 时间步衰减系数范围: 1.0 ~ 1.51 (步长0.01)
- 观点变化增益系数范围: 1.0 ~ 1.51 (步长0.01)
- 合法性约束

生成热力图可视化不同超参数组合下的最终平均观点分布。

#### 5. 一致性分析
对模型判断的一致性进行采样和分析，评估LLM作为评判者的可靠性。

### 技术实现

#### 核心脚本
- `get_data.py`: 数据加载模块
- `last_op_34.py`: 提取最后轮次观点并计算24个影响力/固执度指标
- `total_超参数空间.py`: 超参数空间遍历与热力图生成
- `total_超参数空间_single_inf.py`: 单影响力维度的超参数分析
- `影响力固执度空间.py`: 影响力和固执度空间的可视化
- `参数取值范围矩阵.py`: 参数矩阵计算

#### 数据文件
- `catch_opinion_6all.csv`: 完整的观点演化数据 (~1.2MB)
- `influence_data.pkl`: 预计算的影响力数据
- `convergence_results.csv`: 收敛性分析结果
- `一致性/`: 一致性分析相关数据和脚本

#### 可视化输出
- `heatmaps_upper_right/`: 超参数空间热力图
- `parameter_space.png`: 参数空间可视化
- `影响力固执度空间.csv`: 影响力和固执度的空间分布数据

### 主要发现

1. **偏见碎片化**: 不同模型在处理相同话题时表现出差异化的偏见模式
2. **认知扰动**: 智能体间的交互导致观点的动态演化和不稳定性
3. **对齐错觉**: 表面上的一致性可能掩盖了底层的偏见分歧
4. **影响力不对称**: 正向和负向影响力在不同模型和话题间存在显著差异
5. **固执度特征**: 模型对不同类型观点的坚持程度呈现系统性差异
